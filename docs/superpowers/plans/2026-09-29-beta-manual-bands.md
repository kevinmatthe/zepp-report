# Beta 手动分位范围与图表布局

用户明确要求 Beta 也完整具备优化项，并进一步确认分位范围须手动拖动或输入。交互按用户反馈使用 5 个百分点一档，不使用细碎的 1% 拖动。

- 睡眠、心率、血氧、日内节律独立双端滑杆，直接可见；两侧数字框，输入确认后生效；上下界不交叉，支持 P25–P75 / P10–P90 快捷恢复与隐藏条带。
- 图例移出绘图区并允许换行；标题、图标、切换、范围编辑分区；保留四类指标同级优先级与旧版视觉风格。
- 新增只读分位接口，从原始观测计算完整整数分位供本地拖动使用，不从稀疏分位点近似插值；日内统计沿用每日一个 5 分钟代表值，至少 5 天才显示条带。
- Beta 日内节律支持心率、血氧、压力和点击日期／日历；日期变化、退出和新请求取消旧请求，避免混用指标；缺失不连线，当前日显示最后观测时间和归档更新提示。
- 所有网页与资源需重新验证缓存，避免更新时旧 HTML 与新脚本混用。
- 验证：精确分位、缺失与小样本 API 测试；滑杆实际拖动、键盘与数字输入、交叉限制、隐藏与快捷范围；375/414/768/1024/1440 无溢出且图例不侵入绘图区；真实 30 日归档计算耗时约 0.35 秒。CI 成功后备份、固定 SHA 更新并验证新旧线上页面。
