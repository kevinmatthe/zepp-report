# Beta 样式、同步状态与可调分位范围

用户要求保留 Beta 的同级指标优先级，恢复旧版视觉风格，增加指标图标与今日更新提示，并为睡眠提供均值范围及独立可调分位上下界。

- 保留 /beta 与 /，沿用旧版字体、绿色配色、留白、卡片与差值层次；将设置和统计口径收进图下展开区。
- 四类指标使用内联 SVG；今日同步每 30 秒读取已有状态接口，只有在线且近期成功归档时呼吸。异常与减少动态效果设置会停止动画；含今天的曲线在归档变化后刷新。归档时间不冒充测量时间。
- 睡眠支持总时长、深睡时长和占比；每日值的算术均值与 P25–P75 分布范围，排除今天和缺失；不足 5 夜隐藏范围。深睡占比均值按夜等权，周期表格保留成对时长加权口径。
- 分位上下界支持现有 P10/P25/P50/P75/P90，禁用交叉界限；旧版分布图和日内节律同步支持独立上下界。
- 单元测试覆盖均值、插值分位、缺失和今日排除、低样本与状态过期；浏览器验证刷新、断网停动画、两个非对称分位范围、减少动画、手机与桌面；CI 成功后以固定 SHA 镜像部署并验证实际页面。
